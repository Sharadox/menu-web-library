# @sharadox/menu-web-library

Phone menus that behave: useMenu opens and closes it, locks the page behind, closes on any link or button tapped in the bar or menu, on Escape and when the screen widens.

Built from `template-web-library`: TypeScript in `source/`, one thing per folder, imports by package name, versions from 0.1.0, released by tagging `v<version>` on `index`.
